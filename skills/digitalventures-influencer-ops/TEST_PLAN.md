# DigitalVentures Influencer Ops Skill — Test Plan

## Goal
Verify that the Skill behaves as an evidence-backed, approval-gated operating system and remains compatible with the RDV SaaS domain model.

## Core tests
- Product creation and Product Intelligence
- Creator discovery with source/evidence
- Creator qualification with explicit reasons
- Creator matching using qualified creators only
- Outreach drafting with evidence-backed personalization
- Approval required before sending
- Reply classification and response drafting
- Creator CRM state updates without duplicates
- Creator-to-campaign-to-conversion linkage
- Analytics using stored data only
- Recovery after interrupted workflow

## Pass condition
Every test must produce the expected state/output or clearly identify a blocker. No test may pass by relying on invented data.
