# Prepare Outreach

## Objective
Create evidence-backed outreach drafts for approved creator and campaign matches.

## Procedure
1. Load approved campaign.
2. Load matched creator record.
3. Load creator evidence.
4. Identify genuine personalization points.
5. Draft the message in the campaign's approved tone.
6. State the offer accurately.
7. Remove unsupported claims.
8. Validate personalization against evidence.
9. Save the draft with approval status pending.
10. Stop before external sending.

## Required output
- creator
- channel
- campaign
- message
- personalization evidence
- offer
- approval status
- blockers

Never send from this workflow.
